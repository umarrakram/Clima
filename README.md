# Clima-iOS13

Weather app using URLSession, Core Location, and OpenWeatherMap REST API with delegate pattern and dark mode support.

> **Attribution:** Follow-along project from [Angela Yu's Complete iOS App Development Bootcamp](https://www.appbrewery.co/). Original starter code by [App Brewery](https://github.com/appbrewery/Clima-iOS13).

## What I practiced
- URLSession + Codable (Encodable/Decodable) for REST API calls
- Core Location for GPS coordinates
- Delegate pattern and Swift protocols/extensions
- Grand Central Dispatch (main thread UI updates)
- Dark mode support with vector assets
